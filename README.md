# Machine Learning and Artificial Intelligence Project

This project demonstrates the application of different machine learning techniques using Python and Scikit-learn. It includes supervised learning, unsupervised learning, and neural network approaches.

## Technologies

* Python
* Scikit-learn
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Jupyter Notebook

## Project Structure

The project is organized into several Jupyter notebooks, each focusing on a different machine learning technique:

* `01_linear_regression.ipynb` – Linear Regression
* `02_decision_tree.ipynb` – Decision Tree classification
* `03_knn.ipynb` – K-Nearest Neighbors classification
* `04_neural_network.ipynb` – Multi-Layer Perceptron neural network
* `05_clustering.ipynb` – K-Means and Hierarchical Clustering

## Machine Learning Techniques

### Supervised Learning

The project includes:

* Linear Regression
* Decision Tree
* K-Nearest Neighbors (KNN)
* Multi-Layer Perceptron (MLP)

The classification models were evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

### Unsupervised Learning

The clustering part includes:

* K-Means Clustering
* Hierarchical (Agglomerative) Clustering

The clustering algorithms were compared using the Silhouette Score.

The Elbow Method and dendrograms were also used to help determine the appropriate number of clusters.

## Evaluation

Classification models were evaluated using multiple performance metrics to provide a more complete assessment of their results.

For clustering, the Silhouette Score was used to compare the quality of the clusters produced by K-Means and Hierarchical Clustering.
